## 🚀 Lancer le projet en local

Clonez le dépôt :
```bash
git clone https://github.com/Sohayb1011/portfolio.git
cd portfolio
```

Lancez un serveur HTTP local (au choix) :
```bash
# Avec Python
python -m http.server 8080

# Ou avec Node.js
npx serve .
```

Ouvrez ensuite votre navigateur sur `http://localhost:8080`.
